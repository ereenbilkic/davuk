# Tavuk Vurma Oyunu

Türkçe yapım bir tavuk vurma oyunu. Tamamen tarayıcı üzerinde çalışır.

## Oynanış

- Tavukları vurarak puan kazanın
- Altın tavuklar daha çok puan verir
- Bombalardan kaçının (-3 puan)
- Güç-ups kullanarak avantaj sağlayın
- Görevleri tamamlayarak ek puan kazanın
- Mağazadan skin satın alın

## Özellikler

- 3 zorluk seviyesi (Kolay, Orta, Zor)
- Sonsuz mod ve zamanlı mod
- Yerel liderlik tablosu
- Görev sistemi
- Mağaza ve skin sistemi
- WebAudio ses efektleri

## Dağıtım

Bu oyun GitHub Pages üzerinde dağıtım için optimize edilmiştir.

### Oyunu Oyna

Oyunu canlı olarak buradan oynayabilirsiniz: [GitHub Pages Link]

### Yerel Çalıştırma

```bash
# Python ile
python -m http.server 8000

# Node.js ile
npx serve .

# Veya doğrudan index.html dosyasını tarayıcıda açın
```
